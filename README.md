Frog Hop, a tiny frog-hopping browser game built by an AI agent from one prompt — hop the lily pads, eat the flies, don't splash. The video of the agent building it is posted on X for make.fun's "The agent builds a game from one prompt" bounty. Play it: open game/index.html in a browser (add ?demo=1 to watch it play itself).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
